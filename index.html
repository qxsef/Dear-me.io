Kenapa RuangBebas Ada?

Karena semua orang berhak bersuara. Kadang kita butuh tempat buat jujur tanpa takut dikenal, tanpa takut di-screenshot teman sekelas, tanpa takut di-judge. Web ini dibuat dengan HTML + CSS + JS murni biar bisa jalan di GitHub Pages dan bisa diakses semua orang dari PC maupun laptop.

  • 💜 Bebas tapi sopan — dilarang SARA, doxing, dan spam.
  • 🎭 Anonim, bukan tanpa tanggung jawab — nama samaran tetap tampil.
  • 🔒 Diary = 100% privat — cuma tersimpan di browser lo (localStorage).
