Buatkan website statis dengan HTML + CSS + JavaScript murni saja (yang didukung GitHub Pages), tanpa backend, tanpa framework:

Nama web: RuangBebas, tema warna ungu dominan, modern, optimal untuk PC dan laptop, responsif.

Halaman 1 - Beranda (index.html):
- Penjelasan web tentang kebebasan ekspresi, anonim, gratis, tanpa login, bisa diakses semua orang
- Ada tombol ke Chat Anonim dan Diary Pribadi

Halaman 2 - Chat Anonim (chat.html):
- Chat publik anonim, setiap pesan menampilkan nama samaran penulis + foto profil + jam
- User bisa atur nama samaran dan ganti PFP (upload gambar)
- Bisa kirim teks dan kirim gambar
- Data tersimpan di localStorage

Halaman 3 - Diary Pribadi (diary.html):
- Diary privat hanya tersimpan di browser sendiri (localStorage)
- Ada judul, mood, isi, tanggal otomatis, bisa tambah gambar, bisa hapus
- Ada peringatan privasi bahwa hanya user itu yang bisa lihat

Gaya: ungu (#7c3aed, #a855f7, #4c1d95), dark mode, kartu, navbar, desktop-first dengan max-width 1100px.
Semua teks bahasa Indonesia, santai tapi sopan.
